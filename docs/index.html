Cách thêm một địa điểm

Mở file docs/data/diadiem.json trong repo và thêm một khối như dưới đây (nhớ dấu phẩy giữa các khối):

{
  "ten": "Tên quán / điểm đến",
  "loai": "an",              // an | uong | choi
  "vung": "Miền Nam",        // Miền Bắc | Miền Trung | Miền Nam
  "tinh": "TP. Hồ Chí Minh",
  "toado": [10.7725, 106.6980],   // [vĩ độ, kinh độ]
  "googleMap": "https://maps.app.goo.gl/....",
  "danhgia": 4.6,             // 0–5 (tuỳ chọn)
  "mota": "Vài dòng cảm nhận của bạn.",
  "anh": ["https://link-anh-1.jpg"],
  "video": "https://youtu.be/....",   // tuỳ chọn
  "tags": ["cà phê", "view đẹp"]
}

Lấy toạ độ & link: vào Google Maps → bấm chuột phải vào điểm → toạ độ hiện ra bấm để copy; hoặc bấm “Chia sẻ” để lấy link maps.app.goo.gl.

Lưu lại, commit — trang tự cập nhật.
